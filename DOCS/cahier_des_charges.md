# Cahier des charges — FinSight AI

## 1. Objectif

Créer une plateforme web intelligente permettant d’analyser et améliorer la gestion financière grâce à la Data et au Machine Learning.

## 2. Utilisateurs

- Étudiants
- Particuliers
- Freelances
- PME

## 3. Fonctionnalités

### Authentification
- inscription
- connexion

### Transactions
- ajouter revenus
- ajouter dépenses
- modifier
- supprimer

### Dashboard
- total revenus
- total dépenses
- solde
- graphiques

### Machine Learning

#### Prédiction
- estimation du solde futur
- détection du risque financier

#### Anomalies
- détection des dépenses inhabituelles

### Recommandations
- conseils automatiques

## 4. Contraintes

- utilisation de React.js et FastAPI
- intégration du Machine Learning
- utilisation de GitHub
- utilisation de Jira
- réalisation de maquettes Figma

## 5. Livrables

- code source complet
- documentation
- screenshots
- vidéo démo
- présentation finale
