# FinSight AI

FinSight AI est une plateforme intelligente d’analyse financière utilisant la Data et le Machine Learning.

## Objectif

Aider les utilisateurs à mieux gérer leurs finances, prédire leur trésorerie future et détecter les anomalies financières.

## Technologies

- React.js
- FastAPI
- Python
- Scikit-learn
- MySQL / PostgreSQL
- Chart.js

## Fonctionnalités

- Authentification
- Gestion des transactions
- Dashboard financier
- Prédiction de trésorerie
- Détection d’anomalies
- Recommandations intelligentes

## Structure du projet

- DOCUMENTS : documentation
- ML : machine learning
- BACKEND : API
- FRONTEND : interface utilisateur
- ASSETS : ressources
